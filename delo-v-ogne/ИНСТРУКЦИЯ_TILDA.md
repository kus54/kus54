## 1. Подготовка перед стартом

### Что нужно собрать заранее

| Материал | Требования |
|---|---|
| Логотип | SVG + PNG с прозрачным фоном, min 400×400px |
| Шрифт бренда | TTF/WOFF2 файл или название из Google Fonts |
| Фотографии блюд | min 1920×1080px, JPEG, несколько ракурсов |
| Короткое видео | MP4, до 30 сек, без звука (для фона) / с звуком (для демо) |
| Цвета бренда | HEX-коды фона, текста, акцентов |
| Телефоны | Для заказов и общих вопросов отдельно |
| Ссылки агрегаторов | Яндекс Еда, Самокат, Delivery Club и др. |
| Адрес/ы | Для самовывоза + время работы |

### Регистрация в Tilda
1. Зайти на **tilda.cc** → «Начать бесплатно»
2. Выбрать тариф **Business** (нужен для Zero Blocks и кастомных шрифтов)
3. Создать новый проект → «Одностраничный сайт»

## 3. Создание блоков в Tilda

### БЛОК 1 — HERO (Обложка)

**Способ:** Zero Block (ZB) или стандартный Cover блок

**Шаги:**
1. Нажать «+» добавить блок → **Cover** → выбрать шаблон с тёмным фоном
2. Загрузить видео-фон: настройки блока → «Фон» → «Видео» → загрузить MP4
3. Добавить затемняющий оверлей: «Фон» → «Цвет поверх» → #000000 с opacity 40%
4. Вставить логотип: «Добавить элемент» → «Изображение» → загрузить SVG/PNG лого
5. Заголовок H1: «**Дело в огне**»
6. Подзаголовок: краткий слоган (1 строка, макс 60 символов)
7. CTA-кнопка: «Заказать доставку» → ссылка на блок доставки (`#delivery`)

**Настройки блока:**
- Высота: 100vh (на весь экран)
- Вертикальное выравнивание: по центру
- Мобильная версия: лого сверху, текст по центру, кнопка 100% ширины

---

### БЛОК 2 — О КОНЦЕПЦИИ

**Способ:** Стандартный блок Features (FT101–FT301)

**Шаги:**
1. «+» → «Возможности» (Features) → выбрать сетку 3 колонки
2. Иконки для 3 преимуществ (примеры):
   - 🔥 **Живой огонь** — готовим на открытом огне
   - 🥩 **Только свежее** — мясо от локальных фермеров
   - 🚀 **Быстро** — от заказа до готовности 25 минут
3. Фон раздела: тёмный (#1A0A00)
4. Текст иконок: цвет акцента (#FF4500)

---

### БЛОК 3 — ГАЛЕРЕЯ + ВИДЕО

**Способ:** Стандартная галерея GL + Video блок

**Шаги (Галерея):**
1. «+» → «Галерея» → выбрать Masonry или сетку 3 колонки
2. Загрузить фото блюд (min 6 штук)
3. Настройка: «Открывать в lightbox» = Да

**Шаги (Видео):**
1. «+» → «Видео» → вставить ссылку YouTube/VK Video (лучше VK для РФ)
2. Или: загрузить MP4 напрямую (тариф Business позволяет)
3. Обложка видео: скриншот с языками пламени
4. Настройка: autoplay = Нет, controls = Да

---

### БЛОК 4 — ДОСТАВКА

**Способ:** Zero Block (кастомный) — см. раздел 4

**Шаги:**
1. Создать Zero Block
2. Вставить HTML-код из раздела 4 (шаблон «Блок доставки»)
3. Заменить ссылки на реальные URL страниц вашего заведения в агрегаторах
4. Добавить anchor: в настройках блока → «Идентификатор блока» → `delivery`

---

### БЛОК 5 — КОНТАКТЫ И САМОВЫВОЗ

**Способ:** Стандартный блок Contacts (CN) или Zero Block

**Шаги:**
1. «+» → «Контакты» → выбрать макет с телефонами и адресом
2. Добавить 2 телефона:
   - Заказы и самовывоз: +7 (XXX) XXX-XX-XX
   - Общие вопросы: +7 (XXX) XXX-XX-XX
3. Адрес самовывоза + время работы
4. Кнопка «Позвонить» с href=`tel:+7XXXXXXXXXX`

---

### БЛОК 6 — КАРТА

**Шаги:**
1. «+» → «Карта» → выбрать Яндекс.Карты
2. Вставить адрес → «Стиль карты» → тёмный (dark theme)
3. Или: в Zero Block вставить iframe код карты:

```html
<iframe
  src="https://yandex.ru/map-widget/v1/?um=constructor%3AВАШ_КОД&source=constructor"
  width="100%"
  height="400"
  frameborder="0"
  style="border-radius: 12px;">
</iframe>
```

---

### БЛОК 7 — ФУТЕР

**Шаги:**
1. «+» → «Футер» → выбрать минималистичный тёмный
2. Добавить:
   - Иконки соцсетей (VK, Telegram, Instagram)
   - ИНН / ОГРН (если ИП или ООО) — требование закона
   - «© 2024 Дело в огне. Все права защищены»
   - Ссылка на политику конфиденциальности (нужна для Яндекс.Метрики)

## 4. Zero Block: готовые шаблоны кода

Файлы с кодом:
- `zb-delivery.html` — блок кнопок доставки
- `zb-hero.html` — Hero блок с видеофоном
- `zb-contacts.html` — блок контактов с телефонами
- `zb-features.html` — блок преимуществ

Как добавить Zero Block:
1. «+» → прокрутить в конец → «Zero Block» → «Редактировать»
2. Вкладка «HTML» → вставить код из файла
3. Вкладка «CSS» → вставить стили из файла
4. Сохранить → Закрыть редактор

## 5. Мобильная адаптация

### Настройки в Tilda

**Переключить в мобильный режим:** в редакторе → иконка телефона сверху

Для каждого блока проверить:
- [ ] Шрифты читаемые (min 16px для текста, 24px для заголовков)
- [ ] Кнопки кликабельные (min высота 48px)
- [ ] Колонки схлопываются в 1 (не 3)
- [ ] Нет горизонтальной прокрутки
- [ ] Телефонные номера кликабельные (`tel:` ссылки)
- [ ] Видео не автоплеится на мобиле (расход трафика)
- [ ] Кнопки агрегаторов — полная ширина блока
- [ ] Лого масштабируется корректно

### CSS для мобильной адаптации (вставить в Zero Block)

```css
@media (max-width: 768px) {
  .delivery-grid {
    grid-template-columns: 1fr;
    gap: 16px;
  }

  .delivery-btn {
    width: 100%;
    padding: 18px 24px;
    font-size: 16px;
  }

  .hero-title {
    font-size: 36px;
    line-height: 1.2;
  }

  .features-grid {
    grid-template-columns: 1fr;
  }
}
```

## 6. SEO и продвижение

### Технические настройки в Tilda

#### Метатеги (Настройки сайта → SEO)

**Title страницы:**
```
Дело в огне — шашлык и блюда на огне с доставкой в [Город]
```

**Meta Description (до 160 символов):**
```
Шашлык и блюда на живом огне с доставкой по [Город]. Заказ на Яндекс Еде.
Самовывоз. Звоните: +7 (XXX) XXX-XX-XX. Готовим за 25 минут.
```

**Keywords (для Яндекс):**
```
шашлык доставка [город], блюда на огне, мясо на гриле доставка,
дело в огне, заказать шашлык [город]
```

#### Open Graph (для соцсетей)
В настройках Tilda → SEO → «Изображение для соцсетей»:
- Загрузить фото 1200×630px
- Яркое фото блюд с логотипом

#### Robots.txt и Sitemap
- Tilda генерирует автоматически при публикации
- Проверить: `ваш-домен.ru/robots.txt`
- Проверить: `ваш-домен.ru/sitemap.xml`

---

### Яндекс

#### 1. Яндекс.Вебмастер
1. Зайти на **webmaster.yandex.ru**
2. «Добавить сайт» → вставить URL
3. Верификация: через мета-тег (вставить в Tilda → Настройки → Другой код в `<head>`)
4. Загрузить Sitemap: `ваш-домен.ru/sitemap.xml`
5. Указать регион: ваш город

#### 2. Яндекс.Справочник (ОБЯЗАТЕЛЬНО)
1. **business.yandex.ru** → добавить организацию
2. Заполнить:
   - Название: «Дело в огне»
   - Категория: «Доставка еды», «Шашлычная»
   - Адрес и часы работы
   - Телефон
   - Ссылка на сайт
   - Фотографии (min 5 штук)
3. Получить значок «Проверенная организация»
4. Это даёт попадание в карты Яндекса и карусель с рейтингом

#### 3. Яндекс.Метрика
1. **metrika.yandex.ru** → «Создать счётчик»
2. Вставить код счётчика: Tilda → Настройки → «Код в `<head>`»
3. Настроить цели:
   - «Клик по кнопке доставки»
   - «Клик по номеру телефона»
   - «Просмотр видео»

---

### Google (GCEO / GEO)

#### 1. Google Search Console
1. **search.google.com/search-console**
2. «Добавить ресурс» → «URL-префикс»
3. Верификация через HTML-тег (в Tilda → код в `<head>`)
4. Загрузить Sitemap

#### 2. Google Business Profile (ОБЯЗАТЕЛЬНО для локального SEO)
1. **business.google.com** → «Добавить компанию»
2. Заполнить полностью: название, адрес, часы, фото, ссылка на сайт
3. Верификация по SMS или почте
4. Попросить первых клиентов оставить отзывы → даёт видимость в Google Maps

### Контент-стратегия для SEO

**Тексты на странице должны содержать ключевые слова:**

| Ключевик | Куда вставить |
|---|---|
| «шашлык доставка [город]» | H1, первый абзац |
| «блюда на живом огне» | H2, описание |
| «заказать шашлык» | CTA-кнопки |
| «самовывоз [город]» | Блок контактов |
| «мясо на гриле» | Alt текст фотографий |

**Alt-теги для всех фотографий:**
- Пример: `alt="Шашлык из баранины на мангале — Дело в огне"`
- В Tilda: клик на фото → «Описание» → вставить alt текст

## 7. Подключение домена

### Шаги в Tilda
1. Настройки проекта → «Домен» → «Добавить домен»
2. Вставить купленный домен (без www)
3. Tilda покажет DNS-записи для настройки

### Настройка DNS у регистратора
Добавить записи:
```
Тип: A     Хост: @     Значение: 185.24.218.5
Тип: A     Хост: www   Значение: 185.24.218.5
Тип: CNAME Хост: www   Значение: tilda.ws (альтернатива)
```

### SSL (HTTPS)
- Tilda подключает SSL автоматически (Let's Encrypt)
- Ждать до 24 часов после настройки DNS
- Проверить: замочек в браузере рядом с адресом
