# Инструкция по настройке сайта «Дело в огне» в Tilda
### Приоритет — Яндекс (60%+ поиска в России)

Путь: **Мои сайты → Дело в огне → Настройки сайта**

---

**НАЗВАНИЕ САЙТА**

## 2. Вкладка «Домен»

Здесь подключается ваш домен `delovogne.ru`.

### Шаг 1 — Узнать IP Tilda
1. Нажать **«подключить свой домен»** (ссылка на вкладке Главное) или открыть вкладку **Домен**
2. Ввести `delovogne.ru`
3. Tilda покажет IP-адрес вида `188.XXX.XXX.XXX` — **скопировать его**

### Шаг 2 — Прописать DNS в Beget
1. Войти в **Beget → DNS**
2. Выбрать домен `delovogne.ru`
3. Добавить A-запись:
   - Хост: `@` · Тип: `A` · Значение: IP из Tilda
4. Добавить ещё одну A-запись:
   - Хост: `www` · Тип: `A` · Значение: тот же IP
5. Сохранить. DNS обновится за 1–24 часа.

### Шаг 3 — Подтвердить в Tilda
Когда DNS обновится → вернуться в Tilda → вкладка **Домен** → нажать **Подключить**.
HTTPS (замочек) подключится автоматически за 15–30 минут.

### Редирект delovogne.com → delovogne.ru (в Beget)
1. Beget → Хостинг → папка домена `delovogne.com` → Файловый менеджер
2. Открыть (или создать) файл `.htaccess` в корневой папке
3. Вставить в самое начало:
```apache
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?delovogne\.com$ [NC]
RewriteRule ^(.*)$ https://delovogne.ru/$1 [R=301,L]
```
4. Сохранить → проверить: `delovogne.com` должен перебрасывать на `delovogne.ru`

## 3. Вкладка «Аналитика»

Здесь вставляются счётчики.

### Яндекс Метрика (сделать в первую очередь)
1. Открыть [metrika.yandex.ru](https://metrika.yandex.ru) → **Добавить счётчик**
2. Имя: `Дело в огне` · Сайт: `delovogne.ru` · Часовой пояс: `Новосибирск`
3. Включить **Вебвизор** (записывает поведение посетителей — очень полезно)
4. Создать → скопировать **номер счётчика** (8 цифр)
5. Вернуться в Tilda → вкладка **Аналитика** → поле **Яндекс.Метрика** → вставить номер
6. Нажать **Сохранить изменения**

### Google Analytics (опционально)
1. Открыть [analytics.google.com](https://analytics.google.com) → Создать ресурс → `delovogne.ru`
2. Скопировать **Measurement ID** вида `G-XXXXXXXXXX`
3. Tilda → **Аналитика** → поле **Google Analytics** → вставить ID

## 4. Вкладка «SEO»

Самая важная вкладка для поисковиков.

### Поле «robots.txt»
Вставить:
```
User-agent: *
Allow: /
Disallow: /tilda_*.html

Sitemap: https://delovogne.ru/sitemap.xml
```

### Поле «Код для тега HEAD»
Сюда вставляются верификационные теги. Получить их нужно из двух мест:

**Из Яндекс Вебмастера:**
1. Открыть [webmaster.yandex.ru](https://webmaster.yandex.ru) → **+** → `https://delovogne.ru`
2. Выбрать **HTML-мета-тег** → скопировать тег вида:
   `<meta name="yandex-verification" content="XXXXXXXX" />`

**Из Google Search Console:**
1. Открыть [search.google.com/search-console](https://search.google.com/search-console) → Добавить ресурс → `https://delovogne.ru`
2. Выбрать **HTML-тег** → скопировать тег вида:
   `<meta name="google-site-verification" content="XXXXXXXX" />`

Оба тега вставить в поле «Код для тега HEAD» — каждый с новой строки:
```html
<meta name="yandex-verification" content="ВАШ_КОД" />
<meta name="google-site-verification" content="ВАШ_КОД" />
```

Нажать **Сохранить изменения** → затем **Опубликовать** сайт → вернуться в Вебмастер и нажать **Проверить**.

### Поле «Favicon»
Загрузить иконку логотипа `.png` размером **64×64 пикселя**.
Favicon — маленький значок во вкладке браузера.

## 6. Настройки страницы (отдельно от настроек сайта)

Это не настройки сайта, а настройки конкретной страницы.
В редакторе: нажать на шестерёнку рядом с названием страницы.

### Вкладка «SEO» (страницы)

| Поле | Что вписать |
|------|------------|
| **SEO Title** | `Дело в огне — шашлык с доставкой в Новосибирске, гриль-бар` |
| **SEO Description** | `Гриль-бар «Дело в огне» — шашлык, люля-кебаб, крылья на углях. От 250 г чистого мяса. Доставка через Яндекс Еду и Купер. Самовывоз: пл. Карла Маркса, 5, Новосибирск.` |
| **Keywords** | `шашлык Новосибирск, шашлык с доставкой, гриль-бар Новосибирск, люля-кебаб, мясо на углях` |

> Title — не длиннее 60 символов. Description — не длиннее 155 символов.

2. **Информация о сайте → Регион** → выбрать **Новосибирск** ← обязательно для локального поиска
3. **Индексирование → Robots.txt** → убедиться что файл читается без ошибок

## 9. Schema.org разметка (уже в коде)

Файл `7-schema.html` — вставить **последним блоком** в Tilda (после блока FAQ).
Пользователь не видит, Яндекс и Google читают — понимают что за бизнес, адрес, часы, кухня.

Перед вставкой заменить в файле:
- `+7XXXXXXXXXX` → ваш номер
- `https://vk.com/ВАШ_ВК` → ваша ссылка VK
- `https://t.me/ВАШ_TELEGRAM` → ваш Telegram
- Координаты (взять из Яндекс.Карт: найти точку → правый клик → «Что здесь?»):
  - `"latitude": "54.8617"` → ваша широта
  - `"longitude": "83.1088"` → ваша долгота
