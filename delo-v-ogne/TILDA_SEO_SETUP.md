Домены: **delovogne.ru** (основной) · **delovogne.com** (редирект → .ru)
Хостинг/DNS: **Beget** · Конструктор: **Tilda**

## ШАГ 0. Что вставить в баннер перед публикацией

Файл `t123-blocks/0-preopening.html` — вставить **первым блоком** в Tilda.

Перед вставкой заменить в коде:

| Что найти | Что вставить |
|-----------|-------------|
| `tel:+7XXXXXXXXXX` | ваш номер, пример: `tel:+79131234567` |
| `📞 +7 (XXX) XXX-XX-XX` | ваш номер в читаемом виде |
| `https://t.me/ВАШ_TELEGRAM` | ссылка на ваш Telegram-канал или аккаунт |
| `https://vk.com/ВАШ_ВК` | ссылка на группу ВКонтакте |

| ссылка Яндекс Карты | прямая ссылка на вашу точку (скопировать из Яндекс Карт) |

> Те же ссылки продублировать в `5-contacts.html` (блок контактов).

## ШАГ 1. Редирект delovogne.com → delovogne.ru

### Через Beget (подходит для любого тарифа Tilda)

1. Войти в **Beget** → раздел **Хостинг**
2. Слева выбрать сайт/папку для домена `delovogne.com`
3. Перейти в **Файловый менеджер**
4. Открыть корневую папку домена (обычно `public_html` или папка с именем домена)
5. Найти файл `.htaccess` (если его нет — создать: кнопка «Создать файл», имя `.htaccess`)
6. Открыть файл на редактирование и добавить в самое начало:

```apache
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?delovogne\.com$ [NC]
RewriteRule ^(.*)$ https://delovogne.ru/$1 [R=301,L]
```

7. Сохранить
8. Проверить: открыть в браузере `http://delovogne.com` — должен перебросить на `https://delovogne.ru`

> **301** — постоянный редирект. Поисковики передают весь авторитет домена на новый адрес. Не менять на 302.

### Через Tilda (если подключены оба домена в Tilda)

1. Настройки сайта → **Домен**
2. Добавить `delovogne.ru` → назначить основным
3. Добавить `delovogne.com` → Tilda автоматически поставит 301 на `.ru`

## ШАГ 2. Подключить домен delovogne.ru к Tilda

### 2.1. В Tilda

1. Настройки сайта (шестерёнка вверху) → вкладка **Домен**
2. В поле ввода написать `delovogne.ru` → нажать **Подключить**
3. Tilda покажет нужные DNS-записи (IP-адрес или CNAME)

### 2.2. В Beget

1. Войти в Beget → раздел **DNS**
2. Выбрать домен `delovogne.ru`
3. Добавить запись:
   - Тип: **A**
   - Хост: `@`
   - Значение: IP-адрес из Tilda (вида `188.XXX.XXX.XXX`)
4. Добавить вторую запись:
   - Тип: **A**
   - Хост: `www`
   - Значение: тот же IP-адрес
5. Сохранить → изменения применяются до 24 часов

### 2.3. Проверить

Через 1–24 часа открыть `https://delovogne.ru` — сайт должен открываться.
Проверить SSL (замочек в браузере) — Tilda выдаёт сертификат автоматически.

## ШАГ 5. Настройки сайта → вкладка «SEO»

Открыть: **Настройки сайта** (не страницы) → вкладка **SEO**

**robots.txt** — найти поле и вставить:

```
User-agent: *
Allow: /
Disallow: /tilda_*.html

Sitemap: https://delovogne.ru/sitemap.xml
```

**Favicon:**
1. Подготовить иконку `.ico` или `.png` размером 32×32 или 64×64 px
2. Загрузить в поле Favicon

**Sitemap** генерируется Tilda автоматически по адресу:
`https://delovogne.ru/sitemap.xml` — убедиться что открывается после публикации.

## ШАГ 6. Яндекс Вебмастер

> Обязательно для продвижения в Яндексе, особенно для .ru домена

1. Открыть [webmaster.yandex.ru](https://webmaster.yandex.ru) → войти под аккаунтом Яндекса
2. Нажать **+** → добавить сайт → вписать `https://delovogne.ru`
3. Выбрать способ верификации: **HTML-мета-тег**
4. Скопировать тег вида: `<meta name="yandex-verification" content="XXXXXXXX" />`
5. В Tilda → Настройки сайта → вкладка **SEO** → поле **«Код для тега HEAD»** → вставить тег
6. Опубликовать сайт
7. Вернуться в Яндекс Вебмастер → нажать **Проверить**

После успешной верификации:
- Вкладка **Индексирование → Файл Sitemap** → добавить `https://delovogne.ru/sitemap.xml`
- Вкладка **Информация о сайте → Регион** → выбрать **Новосибирск**
- Вкладка **Поисковые запросы** — через 1–2 недели начнут появляться данные

## ШАГ 7. Google Search Console

1. Открыть [search.google.com/search-console](https://search.google.com/search-console)
2. Нажать **Добавить ресурс** → выбрать **Префикс URL** → вписать `https://delovogne.ru`
3. Способ верификации: **HTML-тег**
4. Скопировать тег вида: `<meta name="google-site-verification" content="XXXXXXXX" />`
5. В Tilda → Настройки сайта → вкладка **SEO** → **«Код для тега HEAD»** → вставить (можно добавить рядом с тегом Яндекса, они не конфликтуют)
6. Опубликовать → вернуться в Google Search Console → **Подтвердить**

После верификации:
- Раздел **Sitemap** → добавить `https://delovogne.ru/sitemap.xml` → Отправить
- Раздел **Покрытие** — через несколько дней появятся проиндексированные страницы

## ШАГ 8. Яндекс Метрика

1. Открыть [metrika.yandex.ru](https://metrika.yandex.ru) → **Добавить счётчик**
2. Имя: `Дело в огне`, сайт: `delovogne.ru`
3. Включить **Вебвизор** (запись поведения пользователей)
4. Создать → скопировать **номер счётчика** (8 цифр, вида `XXXXXXXX`)
5. В Tilda → Настройки сайта → вкладка **Аналитика** → поле **Яндекс Метрика** → вставить номер
6. Опубликовать → через сутки в Метрике появятся первые данные
