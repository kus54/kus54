# Полная инструкция: Tilda + домен + SEO
### «Дело в огне» · delovogne.ru · delovogne.com

> **Приоритет — Яндекс.** В России доля Яндекса ~60–65% поискового трафика.
> Ключевые шаги для Яндекса: Справочник (обязательно!), Вебмастер, Метрика, Schema-разметка, регион Новосибирск.

---

## ЧАСТЬ 1. Подключение домена (Beget + Tilda)

### 1.1. Выбрать основной домен

Основной — **delovogne.ru**
С **delovogne.com** сделаем 301-редирект на .ru (ниже).

---

### 1.2. Получить IP-адрес Tilda

1. Войти в Tilda → открыть сайт «Дело в огне»
2. Нажать **Настройки сайта** (шестерёнка, правый верхний угол)
3. Перейти на вкладку **Домен**
4. Нажать кнопку **Подключить домен**
5. Ввести `delovogne.ru` → Tilda покажет:
   - IP-адрес для A-записи (вида `188.XXX.XXX.XXX`)
   - или CNAME (вида `alias.tilda.ws`)

Скопировать этот адрес — понадобится в Beget.

---

### 1.3. Настроить DNS в Beget

1. Войти в **Beget** → раздел **DNS**
2. В выпадающем списке выбрать домен `delovogne.ru`
3. Найти раздел **A-записи** → нажать **Добавить запись**:

| Поле | Значение |
|------|----------|
| Хост (субдомен) | `@` (означает сам домен без www) |
| Тип | `A` |
| Значение | IP-адрес из Tilda |
| TTL | 600 (или оставить по умолчанию) |

4. Добавить ещё одну A-запись для www:

| Поле | Значение |
|------|----------|
| Хост (субдомен) | `www` |
| Тип | `A` |
| Значение | тот же IP-адрес из Tilda |

5. Нажать **Сохранить**

> DNS-записи применяются от 30 минут до 24 часов. В среднем — 1–2 часа.

---

### 1.4. Подтвердить домен в Tilda

1. Вернуться в Tilda → Настройки сайта → **Домен**
2. Нажать **Проверить** рядом с `delovogne.ru`
3. Когда Tilda скажет «Домен подключён» — готово
4. SSL-сертификат (HTTPS) Tilda выдаёт автоматически в течение 15–30 минут

---

### 1.5. Редирект delovogne.com → delovogne.ru

**Способ через Beget (.htaccess)** — работает всегда:

1. Войти в Beget → **Хостинг**
2. Перейти в папку домена `delovogne.com`
3. Открыть **Файловый менеджер** → корневая папка (`public_html`)
4. Найти файл `.htaccess` (если нет — создать: кнопка «Создать» → имя `.htaccess`)
5. Открыть на редактирование, вставить в самое начало:

```apache
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?delovogne\.com$ [NC]
RewriteRule ^(.*)$ https://delovogne.ru/$1 [R=301,L]
```

6. Сохранить
7. Проверить: открыть `delovogne.com` в браузере → должен перебросить на `delovogne.ru`

> `301` = постоянный редирект. Поисковики перенесут весь «вес» домена на .ru. Не менять на 302.

### Вкладка «SEO»

**Robots.txt** — найти одноимённое поле, вставить:

```
User-agent: *
Allow: /
Disallow: /tilda_*.html

Sitemap: https://delovogne.ru/sitemap.xml
```

**Что это значит:**
- `Allow: /` — разрешить поисковикам индексировать весь сайт
- `Disallow: /tilda_*.html` — закрыть служебные файлы Tilda
- `Sitemap:` — указать где лежит карта сайта

**Код для тега HEAD** — сюда вставить верификационные мета-теги (Яндекс и Google, см. части 4 и 5). Если их несколько — вставить оба, каждый с новой строки.

- **Google Analytics** — вставить Measurement ID (`G-XXXXXXXXXX`)

## ЧАСТЬ 4. Яндекс Вебмастер

> Обязательно для видимости в Яндексе — особенно важно для .ru домена и региона Новосибирск.

### Шаг 1 — Добавить сайт

1. Открыть [webmaster.yandex.ru](https://webmaster.yandex.ru)
2. Войти под аккаунтом Яндекса (создать если нет)
3. Нажать **+** → ввести `https://delovogne.ru` → **Добавить**

### Шаг 2 — Верификация

1. Выбрать способ: **HTML-мета-тег**
2. Скопировать тег вида:
   ```html
   <meta name="yandex-verification" content="abcdef1234567890" />
   ```
3. В Tilda → Настройки сайта → вкладка **SEO** → поле **«Код для тега HEAD»** → вставить тег
4. Нажать **Сохранить** и **Опубликовать** сайт
5. Вернуться в Яндекс Вебмастер → нажать **Проверить**
6. Статус должен смениться на «Подтверждён»

### Шаг 3 — Настроить после верификации

**Индексирование → Файл Sitemap:**
- Нажать **+** → вставить `https://delovogne.ru/sitemap.xml` → **Добавить**
- Sitemap генерируется Tilda автоматически после публикации

**Информация о сайте → Регион:**
- Нажать **Добавить регион** → найти **Новосибирск** → Сохранить
- Это критично для локального поиска — «шашлык Новосибирск»

**Индексирование → Robots.txt:**
- Проверить что файл читается корректно → должен показать содержимое без ошибок

### Шаг 4 — После открытия заведения

После того как уберёте баннер и обновите сайт:
- **Индексирование → Переобход страниц** → запросить переиндексацию
- Раздел **Поисковые запросы** — через 2–4 недели появятся запросы по которым показывается сайт

## ЧАСТЬ 4б. Яндекс.Справочник (Яндекс Бизнес) ← КРИТИЧНО

> Это самый важный шаг для локального поиска. Без него сайт не появится
> на **Яндекс.Картах** и в блоке «Организации» в поиске по запросам
> «шашлык Новосибирск», «гриль-бар рядом», «шашлык пл Карла Маркса».

### Шаг 1 — Создать карточку организации

1. Открыть [business.yandex.ru](https://business.yandex.ru)
2. Войти под аккаунтом Яндекса
3. Нажать **Добавить организацию**
4. Заполнить все поля:

| Поле | Что вписать |
|------|------------|
| **Название** | `Дело в огне` |
| **Рубрика** | `Шашлычная` или `Гриль-бар` |
| **Адрес** | `Новосибирск, площадь Карла Маркса, 5` |
| **Телефон** | ваш номер |
| **Сайт** | `https://delovogne.ru` |
| **Часы работы** | Пн–Вс: 11:00–23:00 |
| **Описание** | `Гриль-бар «Дело в огне» — шашлык, люля-кебаб, куриные крылья и блюда на живом угольном огне. От 250 г чистого мяса. Доставка через Яндекс Еду и Купер. Самовывоз — пл. Карла Маркса, 5.` |

5. Нажать **Сохранить**

### Шаг 2 — Подтвердить адрес

Яндекс предложит варианты подтверждения:
- **Звонок на телефон** — робот продиктует код
- **SMS** — код в сообщении
- Ввести код → организация подтверждена

> Без подтверждения карточка не будет показываться в Картах.

### Шаг 3 — Заполнить карточку полностью

После подтверждения — максимально заполнить профиль:

- **Фотографии** — загрузить логотип + фото заведения и блюд (как появятся)
- **Меню** — добавить позиции с ценами
- **Категории** — добавить дополнительные: `Кафе`, `Доставка еды`, `Шашлычная`
- **Атрибуты** — отметить: доставка, самовывоз, оплата картой, Wi-Fi и т.д.
- **Ссылки соцсетей** — VK, Telegram

> Чем полнее карточка — тем выше позиция в Яндекс.Картах.
> Фотографии особенно важны — карточки с фото кликают в 3–4 раза чаще.

### Шаг 4 — Отзывы

После открытия:
- Попросить первых гостей оставить отзыв на Яндекс.Картах
- 10+ отзывов со средней оценкой 4.5+ резко поднимают позицию в локальном поиске
- Отвечать на все отзывы — Яндекс учитывает активность владельца

## ЧАСТЬ 5. Google Search Console

### Шаг 1 — Добавить ресурс

1. Открыть [search.google.com/search-console](https://search.google.com/search-console)
2. Войти через Google-аккаунт
3. Нажать **+ Добавить ресурс**
4. Выбрать **Префикс URL** (не «Домен» — с ним сложнее верификация)
5. Ввести `https://delovogne.ru` → **Продолжить**

### Шаг 2 — Верификация

1. Выбрать **HTML-тег**
2. Скопировать тег вида:
   ```html
   <meta name="google-site-verification" content="XXXXXXXX" />
   ```
3. В Tilda → Настройки сайта → **SEO** → **«Код для тега HEAD»** → вставить (рядом с тегом Яндекса, они не конфликтуют)
4. Опубликовать сайт → вернуться в Google Search Console → **Подтвердить**

### Шаг 3 — После верификации

**Sitemap:**
- Раздел **Индексирование → Файлы Sitemap**
- Вставить `https://delovogne.ru/sitemap.xml` → **Отправить**
- Статус через 1–3 дня: «Успешно» + покажет количество страниц

**Покрытие:**
- Через несколько дней появятся проиндексированные URL
- Если есть ошибки — Google покажет что именно не так

## ЧАСТЬ 6. Яндекс Метрика

1. Открыть [metrika.yandex.ru](https://metrika.yandex.ru)
2. Нажать **Добавить счётчик**
3. Заполнить:
   - Имя: `Дело в огне`
   - Адрес сайта: `delovogne.ru`
   - Часовой пояс: `Новосибирск (UTC+7)`
4. Включить **Вебвизор** — записывает как пользователи ведут себя на сайте (очень полезно)
5. Нажать **Создать счётчик**
6. Скопировать **номер счётчика** (8 цифр в верхнем левом углу счётчика)
7. В Tilda → Настройки сайта → **Аналитика** → поле **Яндекс Метрика** → вставить номер
8. Опубликовать сайт
9. Проверить: в Метрике через 5–10 минут после первого посещения должен появиться 1 визит
