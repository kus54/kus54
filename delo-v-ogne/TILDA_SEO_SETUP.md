## ⚠️ СРОЧНО — Исправить DNS (вкладка «Домен»)

Tilda показывает ошибку: A-запись указывает на **87.236.16.15** (неверный IP).
Правильный IP Tilda: **176.57.66.40**

**Что сделать прямо сейчас:**
1. Войти в **Beget → DNS** → выбрать `delovogne.ru`
2. Найти A-запись с хостом `@` → изменить значение с `87.236.16.15` на **`176.57.66.40`**
3. Найти A-запись с хостом `www` → изменить значение на **`176.57.66.40`** (или создать если нет)
4. Сохранить
5. Подождать 30–60 минут → вернуться в Tilda → нажать **«Проверить подключение домена»**
6. Обе ошибки должны исчезнуть → домен подключён

## Вкладка «Домен»

Домен `delovogne.ru` уже введён. После исправления DNS (см. выше):

1. Нажать **«Проверить подключение домена»**
2. Дождаться зелёных галочек вместо красных крестиков
3. HTTPS подключится автоматически за 15–30 минут после успешной проверки

**Редирект delovogne.com → delovogne.ru:**
Делается не в Tilda, а в Beget:
1. Beget → Хостинг → папка домена `delovogne.com` → Файловый менеджер
2. Открыть/создать файл `.htaccess` в корне → вставить:
```apache
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?delovogne\.com$ [NC]
RewriteRule ^(.*)$ https://delovogne.ru/$1 [R=301,L]
```
3. Сохранить → проверить: `delovogne.com` должен перебрасывать на `delovogne.ru`

## Вкладка «Аналитика»

### Яндекс Метрика — подключить в первую очередь

1. Открыть [metrika.yandex.ru](https://metrika.yandex.ru) → **Добавить счётчик**
2. Заполнить:
   - Имя счётчика: `Дело в огне`
   - Адрес сайта: `delovogne.ru`
   - Часовой пояс: `Новосибирск (UTC+7)`
3. Включить **Вебвизор** — записывает как гости ходят по сайту (очень полезно)
4. Нажать **Создать счётчик**
5. Скопировать **номер счётчика** — 8 цифр в верхнем левом углу (пример: `12345678`)
6. Вернуться в Tilda → вкладка **Аналитика** → найти поле **Яндекс.Метрика**
7. Вставить номер → **Сохранить изменения**

### Google Analytics (по желанию)

2. Название: `Дело в огне` · URL: `delovogne.ru`
3. Скопировать **Measurement ID** вида `G-XXXXXXXXXX`
4. Tilda → **Аналитика** → поле **Google Analytics** → вставить ID → Сохранить

## Вкладка «SEO»

> На скриншоте вкладка выделена серым — возможно требует проверки тарифа.
> Если недоступна — SEO-теги вставляются через настройки конкретной страницы (см. ниже).

Если вкладка доступна:

### robots.txt
Найти поле **robots.txt**, вставить:
```
User-agent: *
Allow: /
Disallow: /tilda_*.html

Sitemap: https://delovogne.ru/sitemap.xml
```

### Код для тега HEAD
Сюда вставляются мета-теги верификации. Получить их нужно заранее:

**Из Яндекс Вебмастера** ([webmaster.yandex.ru](https://webmaster.yandex.ru)):
- Добавить сайт → `https://delovogne.ru` → верификация через HTML-мета-тег
- Скопировать: `<meta name="yandex-verification" content="ВАШ_КОД" />`

**Из Google Search Console** ([search.google.com/search-console](https://search.google.com/search-console)):
- Добавить ресурс → `https://delovogne.ru` → HTML-тег
- Скопировать: `<meta name="google-site-verification" content="ВАШ_КОД" />`

Вставить оба тега в поле, каждый с новой строки:
```html
<meta name="yandex-verification" content="ВАШ_КОД" />
<meta name="google-site-verification" content="ВАШ_КОД" />
```

### Favicon
Загрузить иконку логотипа: файл `.png`, размер **64×64 пикселя**.
Это значок который отображается во вкладке браузера.
