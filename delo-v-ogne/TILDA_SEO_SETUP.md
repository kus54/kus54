# Инструкция по настройке SEO и публикации — «Дело в огне»

Домены: **delovogne.ru** (основной) · **delovogne.com** (редирект → .ru)
Хостинг DNS: Beget · Конструктор: Tilda

---

## 1. Редирект delovogne.com → delovogne.ru

### Способ A — через Tilda (если тариф позволяет подключить 2 домена)

1. Настройки сайта → **Домен**
2. Добавить оба домена: `delovogne.ru` и `delovogne.com`
3. Основным назначить `delovogne.ru`
4. Tilda автоматически настроит 301-редирект с `.com` на `.ru`

### Способ B — через Beget (работает на любом тарифе Tilda)

1. Войти в **Beget** → **Хостинг** → выбрать сайт `delovogne.com`
2. Открыть **Файловый менеджер** → корневая папка домена (`public_html` или `www`)
3. Создать/открыть файл `.htaccess` и добавить в начало:

```apache
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?delovogne\.com$ [NC]
RewriteRule ^(.*)$ https://delovogne.ru/$1 [R=301,L]
```

4. Сохранить → проверить через браузер: открыть `delovogne.com` — должен уйти на `delovogne.ru`

> **Важно:** 301 — постоянный редирект. Поисковики передадут весь «вес» со старого домена на новый. Не используйте 302.

## 2. Подключить домен в Tilda

1. Настройки сайта → **Домен**
2. Основной URL → ввести `delovogne.ru`
3. Нажать **Подключить** → Tilda покажет DNS-записи для настройки
4. В **Beget → DNS** для `delovogne.ru` добавить A-запись:
   - Тип: `A`
   - Хост: `@`
   - Значение: IP-адрес из Tilda (вида `188.XXX.XXX.XXX`)
5. Ждать до 24 часов на применение DNS

## 4. Настройки сайта → вкладка SEO

**robots.txt** — вставить в поле Robots.txt:

```
User-agent: *
Allow: /
Disallow: /tilda_*.html

Sitemap: https://delovogne.ru/sitemap.xml
```

- **Favicon** — загрузить `.ico` или `.png` 32×32 (вырезать из логотипа)
- **Sitemap** — Tilda генерирует автоматически по адресу `https://delovogne.ru/sitemap.xml`

## 5. Аналитика

### Яндекс Метрика
1. [metrika.yandex.ru](https://metrika.yandex.ru) → Добавить счётчик → указать `delovogne.ru`
2. Скопировать **номер счётчика** (8 цифр)
3. Tilda → Настройки сайта → **Аналитика** → Яндекс Метрика → вставить номер

### Google Analytics (GA4)
1. [analytics.google.com](https://analytics.google.com) → Создать ресурс → `delovogne.ru`
2. Получить **Measurement ID** (вида `G-XXXXXXXXXX`)
3. Tilda → Настройки сайта → **Аналитика** → Google Analytics → вставить ID

---

## 6. Яндекс Вебмастер

1. [webmaster.yandex.ru](https://webmaster.yandex.ru) → Добавить сайт → `https://delovogne.ru`
2. Верификация → **HTML-мета-тег** → скопировать тег
3. Tilda → Настройки сайта → **SEO** → поле «Код для тега HEAD» → вставить тег
4. Опубликовать сайт → вернуться в Вебмастер → нажать **Проверить**
5. После верификации:
   - **Индексирование → Файл Sitemap** → добавить `https://delovogne.ru/sitemap.xml`
   - **Информация о сайте** → Регион → указать **Новосибирск**

---

## 7. Google Search Console

1. [search.google.com/search-console](https://search.google.com/search-console) → Добавить ресурс → `https://delovogne.ru`
2. Верификация → **HTML-тег** → скопировать
3. Tilda → Настройки сайта → **SEO** → «Код для тега HEAD» → добавить (можно несколько тегов)
4. После верификации → **Sitemap** → добавить `https://delovogne.ru/sitemap.xml`
