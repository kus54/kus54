# Инструкция по загрузке сайта «Дело в огне» на Tilda
## Для тех, кто никогда не делал сайты — подробно, по шагам

---

## Что вам понадобится перед началом

1. **Компьютер** (не телефон — редактор Tilda на телефоне неудобен)
2. **Аккаунт Tilda** — у вас он уже есть (вы уже вошли)
3. **Папка с файлами** — все файлы в папке `zero-blocks/` проекта
4. **Программа для открытия текстовых файлов** — подойдёт обычный Блокнот или бесплатный Notepad++ (скачать на notepad-plus-plus.org). **НЕ** Word — он испортит код.

---

## ШАГ 1. Выбрать «Пустую страницу»

Вы уже на экране «Новая страница» — это то, что видно на вашем скриншоте.

> **Нажмите «Выбрать»** под **«Пустая страница»** (первый вариант слева).

Откроется редактор страницы — белое рабочее поле с надписью «Добавьте первый блок».

## ШАГ 2. Первый блок — HERO (главная обложка)

### 2.1 — Открыть файл кода на компьютере

1. Найдите на своём компьютере папку проекта
2. Зайдите в папку `zero-blocks`
3. Откройте файл `zb-hero.html` в Блокноте:
   - Правая кнопка мыши на файле → «Открыть с помощью» → «Блокнот»
4. Выделите **весь текст**: нажмите `Ctrl+A` (выделяет всё)
5. Скопируйте: нажмите `Ctrl+C`
6. **Не закрывайте файл** — он ещё понадобится

### 2.2 — Добавить Zero Block в Tilda

1. В редакторе Tilda нажмите большую кнопку **«+»** или надпись **«Добавьте первый блок»**
2. Появится панель выбора блоков — это библиотека с готовыми шаблонами
3. В **левой панели** прокрутите список категорий до самого конца (Кнопка, Меню, Галерея... Другое)
4. **Ниже** всех категорий, в самом низу панели, найдите кнопку **«Нулевой блок»** — там нарисован прямоугольник с молнией ⚡ и подпись «Создай свой уникальный блок»
5. Нажмите на эту кнопку — блок добавится на страницу

   > **Важно:** Не путайте с блоком «Popup: Zero Block в попапе» (T1093) — он находится в разделе «Другое» и работает иначе (это блок для всплывающих окон). Вам нужен именно **«Нулевой блок»** внизу панели.
   >
   > Также можно нажать вкладку **«ZERO»** в верхней строке фильтров — там сразу покажутся все Zero Block шаблоны, среди которых самый простой пустой блок.

### 2.3 — Открыть редактор Zero Block

1. Наведите мышью на только что добавленный серый блок
2. Появятся кнопки управления — нажмите **«Редактировать»** (карандаш) или **«Content»**
3. Откроется окно Zero Block редактора с двумя вкладками: **HTML** и **CSS**

### 2.4 — Вставить HTML-код

1. Убедитесь что активна вкладка **HTML** (она должна быть подчёркнута)
2. Щёлкните мышью в поле с кодом (там скорее всего уже есть какой-то пустой текст)
3. Выделите всё: `Ctrl+A`
4. Вставьте код который вы копировали: `Ctrl+V`
5. Должен появиться длинный код с `<section class="hero-section">` в начале

### 2.5 — Вставить CSS-код

1. Откройте в Блокноте файл `zb-hero.css` (из той же папки `zero-blocks`)
2. Выделите всё: `Ctrl+A`, скопируйте: `Ctrl+C`
3. Вернитесь в Tilda → нажмите вкладку **CSS**
4. Щёлкните в поле, выделите всё `Ctrl+A`, вставьте `Ctrl+V`

### 2.6 — Сохранить

1. Нажмите кнопку **«Сохранить»** (обычно в правом нижнем или верхнем углу окна)
2. Нажмите **«Закрыть»** или крестик
3. Блок теперь на странице — вы должны увидеть тёмный фон с текстом «Дело в огне»

> **Важно:** Если блок выглядит белым или сломанным — значит вы забыли вставить CSS. Нажмите «Редактировать» на блоке, перейдите на вкладку CSS и вставьте содержимое файла `zb-hero.css`.

### 2.7 — Добавить фото или видео на фон Hero

По умолчанию блок показывает тёмный цвет. Чтобы был фон из фото/видео:

**Вариант А — Фото:**
1. Нажмите на блок Hero правой кнопкой → **«Настройки блока»**
2. Вкладка **«Фон»** → **«Изображение»**
3. Загрузите фото огня/мангала — нажмите «Загрузить»
4. Выберите фото с компьютера

**Вариант Б — Видео (красиво мерцает огонь):**
1. Настройки блока → **«Фон»** → **«Видео»**
2. Загрузите MP4-файл с видео огня
3. Поставьте галочку «Зацикленное» (чтобы крутилось бесконечно)
4. Поставьте галочку «Без звука»

## ШАГ 8. Седьмой блок — Карта Яндекс

Это **НЕ** Zero Block — это обычный встроенный блок Tilda:

1. Нажмите «+» под предыдущим блоком
2. В поиске по блокам (поле поиска вверху панели) наберите: **«карта»**
3. Выберите блок **«Карта»** — там иконка карты с пином
4. Нажмите на блок чтобы он добавился
5. Нажмите на карту → «Редактировать»
6. В поле адрес напишите: `пл. Карла Маркса, 5, [ваш город]`
7. Нажмите «Найти» — карта сама найдёт точку
8. Сохранить

## ШАГ 9. Загрузка фотографий в Tilda

Чтобы фото блюд и заведения отображались на сайте, их нужно сначала загрузить в Tilda, получить ссылку, и вставить в код.

**Как загрузить фото:**

1. В верхнем меню Tilda найдите значок **«Медиа»** или **«Файлы»** (иконка картинки)
2. Нажмите **«Загрузить файл»**
3. Выберите фото с компьютера (формат: JPG или PNG, размер: не больше 2 МБ)
4. Файл загрузится — вы увидите его миниатюру

**Как получить ссылку на фото:**

1. Наведите мышью на загруженное фото
2. Нажмите **правую кнопку мыши**
3. Выберите **«Скопировать ссылку»** или «Копировать адрес»
4. Ссылка скопирована — она будет выглядеть примерно так:
   `https://static.tildacdn.com/tild3100-3433-4632.../photo.jpg`

**Как вставить ссылку в код блока:**

1. Откройте Zero Block который нужно обновить → «Редактировать»
2. Во вкладке HTML нажмите `Ctrl+F` — откроется поиск по коду
3. Найдите текст `ФОТО_ШАШЛЫК_СВИНИНА` (или другое название блюда)
4. Выделите весь `ФОТО_ШАШЛЫК_СВИНИНА.jpg` — **вместе с расширением**
5. Вставьте скопированную ссылку на ваше фото
6. Повторите для каждого фото
7. Сохранить

> **Совет:** Называйте файлы по-русски или на транслите (например `shashlyk-svinina.jpg`) до загрузки — потом будет легче ориентироваться.

## ШАГ 11. Логотип на Hero-блоке

1. Откройте Zero Block с Hero → «Редактировать»
2. Во вкладке HTML найдите строку: `src="ССЫЛКА_НА_ВАШ_ЛОГОТИП.svg"`
3. Загрузите файл логотипа в Медиатеку Tilda (шаг 9)
4. Скопируйте ссылку на логотип
5. Замените `ССЫЛКА_НА_ВАШ_ЛОГОТИП.svg` на реальную ссылку
6. Сохранить

> **Важно:** Для тёмного фона логотип должен быть на прозрачном фоне (формат PNG с прозрачностью). Если у вас логотип только на белом фоне — загрузите и он будет показываться с белым квадратом. Попросите дизайнера дать PNG-версию на прозрачном фоне.

## ШАГ 13. Настройки сайта (SEO и название)

Это делается отдельно от страницы — это «мета»-настройки всего сайта.

1. Вернитесь в панель управления проектом (стрелка «назад» или кнопка с именем сайта вверху)
2. Найдите значок **шестерёнки** или кнопку **«Настройки сайта»**
3. Вкладка **«SEO»**:

   - **Заголовок страницы (Title):**
     ```
     Дело в огне — шашлык на углях с доставкой в [Город]
     ```
   - **Описание (Description):**
     ```
     Шашлык на углях от «Дело в огне». Свежее мясо, живой огонь. Доставка по [Город] через Яндекс Еду. Самовывоз: пл. Карла Маркса, 5. Заказ по телефону.
     ```
   - **OG-изображение** (картинка для ссылки при репосте в мессенджеры):
     Загрузите красивое фото блюда размером 1200×630 пикселей

4. Вкладка **«Аналитика»**:
   - Вставьте счётчик Яндекс.Метрики (если он уже создан)

5. Вкладка **«Дополнительно»** → поле **«Код в `<head>`»**:
   - Откройте файл `zero-blocks/schema.html` в Блокноте
   - Скопируйте весь текст (`Ctrl+A` → `Ctrl+C`)
   - Вставьте в это поле (`Ctrl+V`)
   - Нажмите «Сохранить»

   > Это нужно для того чтобы ваш сайт появлялся в ответах Яндекс.Нейро и Google AI

## ШАГ 14. Просмотр и публикация

### Как посмотреть как выглядит сайт:
1. Нажмите кнопку **«Предпросмотр»** (значок глаза) — откроется в новой вкладке

### Как опубликовать сайт:
1. Нажмите синюю кнопку **«Опубликовать»** (она обычно наверху страницы)
2. Сайт станет доступен по адресу вида: `delo-v-...tilda.ws`
3. Это временный адрес — позже подключите свой домен

### Как подключить свой домен (например delo-v-ogne.ru):
1. Купите домен на reg.ru или nic.ru
2. В настройках сайта Tilda → «Домен» → «Подключить домен»
3. Tilda покажет вам инструкцию с DNS-записями — просто следуйте ей

## Частые вопросы

**«Я вставил код, но ничего не видно — блок белый»**
→ Забыли вставить CSS. Нажмите «Редактировать» на блоке, вкладка «CSS», вставьте содержимое файла `.css`.

**«Фото не отображаются — вижу эмодзи 🔥 вместо фото»**
→ Это нормально — так работают заглушки пока нет реальных фото. Добавьте фото по инструкции в Шаге 9.

**«Вкладки меню не переключаются»**
→ Убедитесь, что вы вставили HTML до конца — в конце `zb-menu.html` есть JavaScript-код. Проверьте что скопировали файл полностью (до `</section>`).

**«Как изменить текст в блоке?»**
→ Нажмите «Редактировать» на блоке → вкладка HTML → найдите нужный текст и поменяйте. Сохраните.

**«Как изменить телефон везде сразу?»**
→ В каждом `.html` файле откройте в Блокноте, нажмите `Ctrl+H` (замена), найдите `+7 (XXX) XXX-XX-XX`, замените на ваш номер.

**«Сайт сохранён, но не опубликован — видит только я»**
→ Нажмите кнопку **«Опубликовать»** в верхней панели редактора. После сохранения изменений всегда нужно нажимать «Опубликовать» заново.
