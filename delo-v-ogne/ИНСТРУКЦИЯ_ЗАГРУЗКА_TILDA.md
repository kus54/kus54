# Инструкция: как загрузить сайт «Дело в огне» на Tilda

## Что у нас есть

В папке `zero-blocks/` лежат готовые блоки для вставки в Tilda:

| Файл | Что это |
|---|---|
| `zb-hero.html` + `zb-hero.css` | Обложка (Hero) с огнём и CTA |
| `zb-features.html` + `zb-features.css` | Блок преимуществ / концепции |
| `zb-menu.html` + `zb-menu.css` | **НОВЫЙ** Меню с вкладками по категориям |
| `zb-gallery.html` + `zb-gallery.css` | **НОВЫЙ** Фотогалерея (снаружи / внутри / готовка) |
| `zb-delivery.html` + `zb-delivery.css` | Доставка + самовывоз пл.Карла Маркса, 5 |
| `zb-contacts.html` + `zb-contacts.css` | Контакты и часы работы |
| `zb-seo-text.html` + `zb-seo-text.css` | **НОВЫЙ** SEO-текст + FAQ для ИИ-поиска |
| `schema.html` | Schema.org разметка для `<head>` |

## ЧАСТЬ 1. Создание проекта в Tilda

### Шаг 1 — Регистрация и проект
1. Зайти на **tilda.cc** → «Начать бесплатно»
2. Нужен тариф **Business** (Zero Blocks, кастомные шрифты, загрузка видео)
3. Нажать **«Создать новый сайт»** → «Одностраничный сайт»
4. Название проекта: «Дело в огне»

### Шаг 2 — Настройки сайта (делать ДО добавления блоков)
1. Зайти в **Настройки сайта** (шестерёнка справа вверху)
2. Вкладка **«Общее»**:
   - Название: `Дело в огне — шашлык и блюда на огне с доставкой`
   - Язык сайта: Русский
3. Вкладка **«SEO»**:
   - Title: `Дело в огне — шашлык и блюда на огне с доставкой в [Город]`
   - Description: `Шашлык и блюда на живом огне с доставкой по [Город]. Заказ через Яндекс Еду. Самовывоз: пл. Карла Маркса, 5. Звоните: +7 (XXX) XXX-XX-XX. Готовим за 25 минут.`
   - OG Image: загрузить фото 1200×630px (яркое фото блюда с логотипом)
4. Вкладка **«Аналитика»**:
   - Вставить счётчик Яндекс.Метрики (получить на metrika.yandex.ru)
   - Вставить счётчик Google Analytics (опционально)
5. Вкладка **«Дополнительно»** → поле **«Код в `<head>`»**:
   - Скопировать **всё содержимое** файла `zero-blocks/schema.html`
   - Вставить туда (это Schema.org для ИИ-поиска и Google)

```
3. МЕНЮ          ← zb-menu.html        (НОВЫЙ)
4. ГАЛЕРЕЯ       ← zb-gallery.html     (НОВЫЙ)
5. ДОСТАВКА      ← zb-delivery.html
6. КОНТАКТЫ      ← zb-contacts.html
7. КАРТА         ← стандартный блок Tilda «Карта» → Яндекс.Карты
8. SEO-ТЕКСТ     ← zb-seo-text.html    (НОВЫЙ)
9. ФУТЕР         ← см. ниже
```

## ЧАСТЬ 3. Как вставить каждый Zero Block

### Общий порядок для КАЖДОГО блока:

1. В редакторе страницы нажать **«+»** (добавить блок)
2. Прокрутить список блоков вниз до раздела **«Другое»** → **«Zero Block»**
3. Нажать **«Редактировать Zero Block»**
4. Откроется редактор с вкладками **HTML** и **CSS**

**В вкладке HTML:**
- Открыть файл `zb-НазваниеБлока.html` (в папке `zero-blocks/`)
- Выделить всё (`Ctrl+A`), скопировать (`Ctrl+C`)
- В редакторе Tilda щёлкнуть на вкладку **HTML**, выделить всё, вставить

**В вкладке CSS:**
- Открыть файл `zb-НазваниеБлока.css`
- Выделить всё, скопировать
- В редакторе Tilda щёлкнуть на вкладку **CSS**, выделить всё, вставить

5. Нажать **«Сохранить»** → **«Закрыть»**
6. Проверить отображение в превью

> **Важно:** Если блок выглядит белым или пустым — скорее всего, не вставлен CSS. Проверьте вкладку CSS.

## ЧАСТЬ 4. Инструкции по каждому блоку

### БЛОК 1 — HERO (`zb-hero.html`)

1. Вставить HTML и CSS (см. шаги выше)
2. Заменить `src="ССЫЛКА_НА_ВАШ_ЛОГОТИП.svg"` → реальный URL логотипа
   _(загрузить лого в Tilda: Медиатека → загрузить файл → скопировать ссылку)_
3. Заменить `href="tel:+7XXXXXXXXXX"` → ваш реальный номер телефона
4. В настройках блока Tilda → **«Фон»** → **«Видео»** → загрузить MP4-видео с огнём (до 30 сек)
5. Anchor блока: в настройках → **«ID блока»** → не нужен (это первый блок)

---

### БЛОК 2 — ПРЕИМУЩЕСТВА (`zb-features.html`)

1. Вставить HTML и CSS
2. При желании отредактировать 3 текстовых преимущества под ваши слова
3. Цитата внизу — тоже редактируется

---

### БЛОК 3 — МЕНЮ (`zb-menu.html`) ← НОВЫЙ

1. Вставить HTML и CSS
2. **Добавить фото блюд:**
   - В каждой карточке `<img src="ФОТО_ИМЯ.jpg" ...>` — заменить `src` на URL реального фото
   - URL получить: в Tilda → **Медиатека** → загрузить фото → правая кнопка → «Скопировать ссылку»
3. **Проверить и отредактировать:**
   - Названия блюд
   - Описания (состав и вес)
   - Цены (`от XXX ₽`)
4. **Anchor блока:** в настройках → **«ID блока»** → `menu`
5. Табы работают автоматически через JS (уже встроен)

> **Совет:** Начните с 4–6 позиций «Мясо на мангале» — это главная категория. Остальные категории заполните позже.

---

### БЛОК 4 — ГАЛЕРЕЯ (`zb-gallery.html`) ← НОВЫЙ

1. Вставить HTML и CSS
2. **Добавить фото заведения:**
   - Замените каждый `src="ФОТО_НазваниеФото.jpg"` на реальный URL
   - Рекомендуется min 12 фото: 4 снаружи + 4 внутри + 4 процесс готовки
   - Минимальный размер фото: 800×600px
   - Оптимальный формат: JPEG, сжатый до 200–400 КБ
3. **Что снять для раздела «Снаружи»:**
   - Фасад днём и вечером, вывеска, терраса, парковка
4. **Что снять для раздела «Внутри»:**
   - Общий вид зала, уютные столики, барная стойка, детали интерьера
5. **Что снять для раздела «Процесс»:**
   - Горящий мангал, повар у огня, мясо на решётке, красивая подача
6. **Anchor блока:** в настройках → **«ID блока»** → `gallery`

---

### БЛОК 5 — ДОСТАВКА (`zb-delivery.html`)

1. Вставить HTML и CSS
2. **Заменить ссылки агрегаторов** (3 штуки):
   - `href="https://eda.yandex.ru/ВАША_ССЫЛКА"` → ваша реальная страница на Яндекс Еде
   - `href="https://www.deliveryclub.ru/ВАША_ССЫЛКА"` → ваша страница на Delivery Club
   - `href="https://samokat.ru/ВАША_ССЫЛКА"` → ваша страница на Самокате
3. **Заменить телефон** в блоке самовывоза:
   - `href="tel:+7XXXXXXXXXX"` → ваш реальный номер
   - Текст `+7 (XXX) XXX-XX-XX` → ваш реальный номер
4. **Anchor блока:** в настройках → **«ID блока»** → `delivery`

---

### БЛОК 6 — КОНТАКТЫ (`zb-contacts.html`)

1. Вставить HTML и CSS
2. Заменить все `+7 (XXX) XXX-XX-XX` → ваш реальный номер
3. Заменить `href="tel:+7XXXXXXXXXX"` → ваш реальный номер в формате +7XXXXXXXXXX
4. Заменить `href="https://t.me/ВАШ_TELEGRAM"` → ваш реальный Telegram
5. Заменить `ул. Примерная, д. 1` → `пл. Карла Маркса, 5`
6. Заменить ссылку Яндекс.Карты → реальная ссылка на вашу точку
7. **Anchor блока:** в настройках → **«ID блока»** → `contacts`

---

### БЛОК 7 — КАРТА

1. Нажать **«+»** → **«Карта»** → выбрать **Яндекс.Карты**
2. В поле адрес вписать: `пл. Карла Маркса, 5, [Ваш город]`
3. Стиль карты → выбрать тёмный (Dark)
4. Высота карты: 400px

---

### БЛОК 8 — SEO-ТЕКСТ + FAQ (`zb-seo-text.html`) ← НОВЫЙ

1. Вставить HTML и CSS
2. Заменить все `[Город]` → ваш реальный город (через Ctrl+H в текстовом редакторе)
3. Проверить и при желании отредактировать:
   - Текст о концепции (3 абзаца)
   - Цифры в карточках-фактах (25 мин, 4+ вида и т.д.)
   - Вопросы и ответы FAQ — они уже оптимизированы для ИИ-поиска
4. **Anchor блока:** в настройках → **«ID блока»** → `about`

> **Зачем FAQ?** Яндекс.Нейро, Google SGE, ChatGPT Search и Perplexity берут ответы прямо из FAQ-блоков. Это даёт бесплатные показы в блоках ИИ-ответов без клика конкурентов.

---

### БЛОК 9 — ФУТЕР

1. Нажать **«+»** → **«Футер»** → выбрать минималистичный тёмный шаблон
2. В блоке футера отредактировать текст:
   - **Копирайт:** `© 2026 Дело в огне — все права защищены`
   - **Юридика:** `ИП [Фамилия И.О.], ИНН [XXXXXXXXXXXX], ОГРНИП [XXXXXXXXXXXXXXX]`
3. Добавить ссылки:
   - Политика конфиденциальности
   - Использование cookie
   - Публичная оферта
4. Иконки соцсетей: VK, Telegram

---

### БЛОК 10 — БАННЕР COOKIE (обязательно по закону РФ)

Tilda встроенного инструмента для cookie-баннера нет, поэтому:

**Способ A — Zero Block (рекомендуется):**
1. Добавить последний Zero Block на странице
2. Вставить этот HTML:
```html
<div class="cookie-notice" id="ckb">
  <p>Сайт использует cookie для аналитики (Яндекс.Метрика) и улучшения работы.
  Оставаясь на сайте, вы соглашаетесь с <a href="/cookie-policy">политикой использования cookie</a>.</p>
  <button onclick="document.getElementById('ckb').style.display='none'; localStorage.setItem('ck','1')">Принять</button>
</div>
<script>if(localStorage.getItem('ck')) document.getElementById('ckb').style.display='none';</script>
```

CSS:
```css
.cookie-notice {
  position: fixed; bottom: 0; left: 0; right: 0; z-index: 9999;
  background: rgba(10,4,0,0.97); border-top: 1px solid rgba(255,69,0,0.3);
  padding: 14px 20px; display: flex; align-items: center; gap: 20px; flex-wrap: wrap;
  font-family: 'Arial', sans-serif;
}
.cookie-notice p { font-size: 13px; color: rgba(255,255,255,0.6); flex: 1; margin: 0; line-height: 1.5; }
.cookie-notice a { color: #FF4500; }
.cookie-notice button {
  background: #FF4500; color: #fff; border: none; padding: 9px 20px;
  border-radius: 6px; font-size: 14px; font-weight: 600; cursor: pointer;
}
```

**Способ B — сервис OneTrust или Cookiebot** (платные, но более полные)

## ЧАСТЬ 5. Создание страниц для юридических документов

По требованиям Роскомнадзора и закона №152-ФЗ нужны три страницы.

### Как создать отдельные страницы в Tilda:
1. В панели проекта → **«Добавить страницу»**
2. Выбрать пустую страницу
3. Добавить стандартный текстовый блок

### Политика конфиденциальности (страница `/privacy-policy`)
Минимальное содержание:
- Кто собирает данные (название ИП/ООО, ИНН)
- Какие данные собираем: имя, телефон, IP-адрес, cookie
- Зачем: обработка заказов, аналитика
- Передача третьим лицам: Яндекс.Метрика, сервисы доставки
- Права пользователя: удаление данных (указать email или телефон)
- Срок хранения
- Дата последнего обновления

### Политика cookie (страница `/cookie-policy`)
- Что такое cookie
- Какие cookie мы используем (Яндекс.Метрика, технические)
- Как отказаться (настройки браузера)
- Срок хранения cookie

### Публичная оферта (страница `/oferta`)
- Только если принимаете онлайн-заказы напрямую (не через агрегаторы)
- Условия заказа, оплаты, доставки, возврата

> **Если вы только перенаправляете на Яндекс Еду/Delivery Club**, оферта не обязательна — они сами несут юридическую ответственность за заказы.

## ЧАСТЬ 6. Schema.org — что заменить

Открыть файл `zero-blocks/schema.html` и заменить:

| Найти | Заменить на |
|---|---|
| `[ВАШ-ДОМЕН]` | ваш-домен.ru (без https://) |
| `[XXXXXXXXXX]` (в телефоне) | 10 цифр вашего номера без +7 |
| `[ПОЧТА@ДОМЕН.RU]` | ваша рабочая почта |
| `[ул. Примерная, д. 1]` | пл. Карла Маркса, 5 |
| `[Город]` | ваш реальный город |
| `[Регион]` | ваш регион (напр. «Кемеровская область») |
| `[123456]` | ваш почтовый индекс |
| `[55.000000]` | широта вашей точки (из Яндекс.Карт) |
| `[37.000000]` | долгота вашей точки |
| `[ВАШ_ПРОФИЛЬ_VK]` | ваш username VK |
| `[ВАШ_TELEGRAM]` | ваш username Telegram |
| `[Город]` в FAQPage | ваш город во всех вопросах |

После заполнения — вставить целиком в Tilda → Настройки сайта → **«Код в `<head>`»**.

## ЧАСТЬ 7. Фотографии — технические требования

### Фото блюд (для блока меню):
- Размер: минимум 800×600px, рекомендуется 1200×900px
- Формат: JPEG, качество 80–85%
- Фон: тёмный или нейтральный, хорошее освещение
- Ракурс: сверху под углом 45° или прямо сверху

### Фото заведения (для галереи):
- Размер: минимум 1200×900px
- Снять при естественном свете (днём)
- Вечерние фото с подсветкой — отдельно
- Фото мангала с огнём — это самый важный кадр

### Как загрузить в Tilda:
1. В проекте → **«Медиатека»** (значок галереи сверху)
2. Перетащить или кнопка **«Загрузить»**
3. После загрузки: навести на фото → **«Скопировать ссылку»**
4. Вставить ссылку вместо `ФОТО_ИМЯ.jpg` в коде блока

## ЧАСТЬ 8. Подключение домена

1. Купить домен: ru-center.ru, reg.ru, nic.ru или другой регистратор
2. В Tilda: **Настройки сайта** → **«Домен»** → **«Подключить домен»**
3. Ввести домен без `www`
4. Tilda покажет две A-записи и CNAME-запись
5. У регистратора домена: раздел «DNS» → добавить эти записи
6. Ждать до 24 часов — DNS обновится, SSL подключится автоматически

## ЧАСТЬ 10. Частые ошибки и как их исправить

| Проблема | Решение |
|---|---|
| Блок белый / пустой | Не вставлен CSS. Проверьте вкладку CSS в Zero Block |
| Табы меню не работают | Не вставлен JS — он в конце `zb-menu.html`, после `</section>` |
| Фото не показываются | В `src=` вставлен неполный URL. Скопируйте ссылку заново из Медиатеки |
| Cookie-баннер не скрывается | Очистить кэш браузера → кнопка «Принять» |
| Телефон не кликается | Проверьте формат `href="tel:+7XXXXXXXXXX"` без пробелов |
| Карта не грузится | Яндекс.Карты требуют API-ключ. В бесплатном тарифе использовать iframe |
| Schema.org не принята | Проверить в Rich Results Test. Скорее всего, не заменены `[заглушки]` |
| Сайт не индексируется | Проверить robots.txt: там должно быть `Allow: /`, не `Disallow: /` |
