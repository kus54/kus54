# SEO Чеклист — «Дело в огне»
## Быстрый старт: что сделать в первую неделю

---

## 🔴 КРИТИЧНО (без этого сайт не найдут)

### 1. Мета-теги (Tilda → Настройки → SEO)

```
Title:       Дело в огне — шашлык и блюда на огне с доставкой в [Город]
Description: Шашлык и блюда на живом огне. Доставка через Яндекс Еду.
             Самовывоз. Звоните: +7 (XXX) XXX-XX-XX. Готовим 25 минут.
```

> **Правило:** Title — до 60 символов, Description — до 160 символов.
> Обязательно укажите город в Title.

---

### 2. Яндекс.Справочник → business.yandex.ru

Зарегистрироваться ОБЯЗАТЕЛЬНО — даёт:
- Карточка в Яндекс.Картах
- Отображение в поиске Яндекса с рейтингом
- Карусель с фото и часами работы

Что заполнить:
- [x] Название: «Дело в огне»
- [x] Рубрика: «Доставка еды», «Шашлычная» (обе!)
- [x] Адрес + координаты
- [x] Телефон
- [x] Часы работы (в т.ч. праздники)
- [x] Сайт
- [x] Фото (min 10 штук, лучше 20)
- [x] Описание (400–500 символов с ключевыми словами)

---

### 3. Google Business Profile → business.google.com

Аналог Яндекс.Справочника для Google:
- Даёт карточку в Google Maps
- Показывается в правой колонке при поиске
- Отзывы влияют на позиции

Что заполнить: те же поля, что и в Яндекс.Справочнике

---

### 4. Alt-теги всех изображений (Tilda → клик на фото → Описание)

Примеры:
```
Шашлык из свинины на мангале — Дело в огне [Город]
Люля-кебаб на открытом огне — доставка [Город]
Мясное ассорти гриль — ресторан Дело в огне
Антрекот на углях — заказать доставку [Город]
```

## 🟡 ВАЖНО (сделать в первый месяц)

### 5. Schema.org разметка

Вставить в Tilda → Настройки → «Код в `<head>`» (файл schema.html)

Что даёт:
- Расширенные сниппеты в поиске (звёздочки, часы)
- Лучшее понимание сайта поисковиком
- Голосовой поиск («Алиса, закажи шашлык»)

---

### 6. Скорость загрузки

Проверить: **PageSpeed Insights** (pagespeed.web.dev)
Цель: Score 80+ на мобиле, 90+ на десктопе

Типичные проблемы и решения в Tilda:
| Проблема | Решение |
|---|---|
| Большие фото | Сжать через squoosh.app (WebP формат) |
| Много шрифтов | Использовать только 1-2 начертания |
| Много видео | Использовать превью + загрузка по клику |

---

### 7. Robots.txt и Sitemap

- Sitemap генерируется Tilda автоматически: `ваш-домен.ru/sitemap.xml`
- Загрузить sitemap в Яндекс.Вебмастер и Google Search Console
- Проверить robots.txt: `ваш-домен.ru/robots.txt`

## 🟢 ДОПОЛНИТЕЛЬНО (для роста через 1-3 месяца)

### 9. Контент-маркетинг

- Завести страницу в VK: публикуйте фото блюд еженедельно
- Telegram-канал: акции, новинки меню, за кулисами
- Отвечать на ВСЕ отзывы в Яндекс.Картах и Google Maps

### 10. Локальное SEO

- Название в Яндекс.Справочнике = Название на сайте = Название в Google = «Дело в огне»
- Адрес везде одинаковый (включая пунктуацию)
- Телефон везде одинаковый (формат: +7 (XXX) XXX-XX-XX)
- Это называется NAP-консистентность — критично для локального ранжирования

### 11. Отзывы

Для роста в поиске нужны отзывы:
- Просить каждого 5-го клиента оставить отзыв в Google Maps
- QR-код на упаковке/чеке → прямая ссылка на форму отзыва
- Отзывы с фото = в 3 раза больше влияния на ранжирование
