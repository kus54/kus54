## 1. ЛОГОТИП

### Важно: нужен PNG с прозрачным фоном

Сайт тёмный. Если у логотипа белый фон — он будет виден как белый прямоугольник.
Нужна версия **PNG с прозрачным фоном** (без белого фона).

**Как убрать белый фон бесплатно:**
1. Зайдите на **remove.bg** (бесплатный сервис)
2. Загрузите логотип → он автоматически уберёт фон
3. Скачайте результат в PNG
4. Используйте этот файл

---

### Шаг 1 — Подготовить файл

Форматы которые подходят:
| Формат | Когда использовать |
|---|---|
| **PNG с прозрачным фоном** | Лучший вариант — рекомендуем |
| **SVG** | Идеально если есть — векторный, не теряет качество |
| JPG | Не подходит для тёмного фона |

Рекомендуемый размер файла: ширина от 400 до 800px, не тяжелее 200 КБ.

---

### Шаг 2 — Загрузить логотип в Tilda

1. Откройте редактор Tilda
2. В левом меню нажмите значок **«Медиа»** (картинка с горой) или **«Файлы»**
3. Нажмите **«Загрузить файл»** → выберите PNG логотипа
4. После загрузки нажмите на файл — справа появится **ссылка (URL)**
5. Скопируйте эту ссылку — она нужна для следующего шага

---

### Шаг 3 — Вставить логотип в блок Герой

В коде блока `1-hero.html` уже есть место для логотипа. Нужно только вставить ссылку.

1. Найдите блок Герой на странице → нажмите **«Контент»**
2. Найдите в коде строку:
```
src="ВСТАВЬТЕ_ССЫЛКУ_НА_ЛОГОТИП"
```
3. Замените `ВСТАВЬТЕ_ССЫЛКУ_НА_ЛОГОТИП` на скопированную из Tilda Медиа ссылку
4. Нажмите **«Сохранить и закрыть»**
5. Нажмите **«Опубликовать»**

---

### Как заменить логотип на другой (в будущем)

Всё то же самое — просто замените ссылку:

1. Загрузите новый логотип в Tilda Медиа → скопируйте новую ссылку
2. Откройте блок Герой → **«Контент»**
3. Найдите строку `src="...старая ссылка..."` → замените на новую
4. Сохраните → Опубликуйте

Старую версию логотипа можно удалить из Tilda Медиа если она больше не нужна.

## 2. ФОТО ТОЧКИ (ГАЛЕРЕЯ)

Для фото используем **встроенный блок Tilda «Галерея»** — это проще, чем T123.

### Шаг 1 — Добавить блок галереи

1. Нажмите **«+»** в нужном месте страницы
2. Выберите раздел **«Галерея»** в левой панели
3. Выберите любой понравившийся шаблон галереи (рекомендую вид «Сетка» или «Слайдер»)

### Шаг 2 — Загрузить фотографии

1. Наведите на блок галереи → нажмите **«Контент»**
2. Нажмите каждое фото-место → загрузите своё фото
3. Можете добавить подпись: «Внутри», «Мангал», «Атмосфера» и т.д.

### Порядок блоков на странице (рекомендую):

```
[Блок 1 — Герой]
[Блок 2 — Преимущества]
[Блок 3 — Меню]
[ГАЛЕРЕЯ — фото снаружи и внутри]   ← добавить сюда
[Блок 4 — Доставка]
[Блок 5 — Контакты]
[Яндекс Карта]                       ← добавить сюда
[Блок 6 — SEO/FAQ]
```

**Совет по фото:** делайте фото горизонтальные (альбомные), размер от 1200px по ширине, не тяжелее 1 МБ.

## 3. МЕНЮ — ОБНОВИТЬ БЛЮДА И ЦЕНЫ

Меню находится в файле `t123-blocks/3-menu.html`.

### Что менять:

Откройте файл в Блокноте. Найдите блок вашего блюда — выглядит так:

```html
<h3 class="menu-card__title">Шашлык из свинины</h3>
<p class="menu-card__desc">Шея, маринад из лука и специй, живой огонь. 300 г.</p>
<span class="menu-card__price">от 450 ₽</span>
```

- Измените название → `Шашлык из свинины`
- Измените описание → `Шея, маринад из лука...`
- Измените цену → `от 450 ₽`

Сохраните файл, вставьте в блок T123 заново.

### Добавить реальное фото блюда:

Загрузите фото в Tilda Медиа → скопируйте ссылку.
Найдите в карточке блюда:
```html
<div class="menu-card__img-placeholder">🥩</div>
```
Замените на:
```html
<div class="menu-card__img-placeholder" style="background-image:url('ССЫЛКА_НА_ФОТО'); background-size:cover; background-position:center;"></div>
```

## 4. ЯНДЕКС КАРТА

### Вариант А — Встроенный блок Tilda (проще)

1. Нажмите **«+»** на странице
2. Выберите раздел **«Другое»** → блок **«Яндекс Карта»** (или просто «Карта»)
3. В настройках блока введите ваш адрес
4. Карта отобразится автоматически

### Вариант Б — Ссылка «На карте» в блоке Контакты

1. Зайдите на **yandex.ru/maps**
2. Найдите вашу точку на карте
3. Нажмите **«Поделиться»** → скопируйте ссылку
4. Откройте блок «Контакты» (5-contacts.html) на редактирование в T123
5. Найдите строку:
   ```html
   <a href="https://yandex.ru/maps/" ...>На карте</a>
   ```
6. Замените `https://yandex.ru/maps/` на вашу скопированную ссылку
7. Сохраните

## 5. ССЫЛКИ НА АГРЕГАТОРЫ ДОСТАВКИ

### Как найти свои ссылки:

- **Яндекс Еда**: откройте приложение YE → найдите ваше заведение → кнопка «Поделиться» → скопируйте ссылку
- **Delivery Club**: аналогично в приложении DC
- **Самокат**: аналогично

### Где вставить в код:

Откройте `t123-blocks/4-delivery.html` в Блокноте. Найдите:

```html
<a href="https://eda.yandex.ru/" target="_blank" ...>
```

Замените `https://eda.yandex.ru/` на вашу реальную ссылку. То же для остальных кнопок.

Вставьте обновлённый файл в T123 блок доставки.

## 6. SEO И GSEO (ИНФОРМАЦИЯ О КОМПАНИИ)

SEO — это то, как сайт находят в Яндексе и Google.
GSEO — это то, как ИИ (Яндекс Нейро, ChatGPT Search) отвечают на вопросы о вашем заведении.

### Часть А — Добавить SEO/FAQ блок на страницу

Файл: `t123-blocks/6-seo-faq.html`

Добавьте его как T123 блок в самый конец страницы (после контактов).
Перед добавлением откройте файл и замените все `[Город]` на ваш реальный город.

### Часть Б — Добавить Schema.org в настройки сайта (для поисковиков)

Это невидимый код, который читают Яндекс, Google и ИИ-поисковики.

1. Откройте файл `zero-blocks/schema.html` в Блокноте
2. Замените все значения в `[квадратных скобках]` на реальные:

| Что заменить | На что |
|---|---|
| `[Город]` | Ваш город (например: Москва) |
| `[ВАШ-ДОМЕН]` | Адрес вашего сайта (например: delovogne.ru) |
| `[XXXXXXXXXX]` | Ваш номер телефона без +7 |
| `[Регион]` | Ваш регион (например: Московская область) |
| `[123456]` | Ваш почтовый индекс |
| `[55.000000]` | Широта (из Яндекс Карт) |
| `[37.000000]` | Долгота (из Яндекс Карт) |
| `пл. Карла Маркса, 5` | Ваш реальный адрес |

3. Скопируйте весь файл
4. В Tilda: **Настройки сайта** → вкладка **«Ещё»** → поле **«Код в head»**
5. Вставьте туда скопированный код
6. Сохраните

### Как найти координаты в Яндекс Картах:

1. Откройте **yandex.ru/maps**
2. Найдите вашу точку → нажмите правой кнопкой мыши
3. Выберите **«Что здесь?»**
4. Вверху появятся координаты — скопируйте (первое число = широта, второе = долгота)
