AI-маркетинговая система на базе [ai-marketing-skills](https://github.com/ericosiu/ai-marketing-skills), адаптированная под шашлычную "Дело в Огне".


## Быстрый старт

### Создать пост для ВК

Дай Claude задание:
```
Напиши пост для ВКонтакте про шашлык из свинины.
Используй brand.md для голоса, menu.md для деталей,
patterns.md для правил. Прогони через эксперта vk-instagram.md.
```

### Оценить готовый пост

```
Expert panel этот текст: [текст поста]
Используй панель experts/vk-instagram.md.
Минимальный балл для публикации — 90/100.
```

### Запустить A/B эксперимент

```
Создай эксперимент: тест заголовков для поста про люля-кебаб.
Вариант A: вопрос-провокация.
Вариант B: конкретные цифры.
Метрика: охват + лайки.
```

## Контент-план (шаблон недели)

| День | Тема | Формат | Канал |
|------|------|--------|-------|
| Пн | Открываем неделю с правильного шашлыка | Пост + фото | ВК |
| Ср | Процесс: как готовится люля-кебаб | Видео-сторис | ВК / TG |
| Чт | Настойки — что и к чему | Карточки | ВК |
| Пт | Пятничный призыв (компания, комплекс) | Пост + акция | ВК / TG |
| Сб | За кадром: угли, мангал, утро | Reels/клип | Instagram |
| Вс | Шашлык в лаваше — формат выходного дня | Пост | ВК |

## Правила публикации

1. **Перед созданием** — прочитай `references/patterns.md`
2. **При создании** — используй голос из `references/brand.md`
3. **Перед публикацией** — прогони через `experts/vk-instagram.md` (порог 90+)
4. **После публикации** — залоггируй метрики в `experiments/` для A/B анализа
5. **Еженедельно** — обновляй `patterns.md` по результатам

## Ключевые эксперименты для запуска

| # | Гипотеза | Переменная | Метрика |
|---|---------|-----------|---------|
| 1 | Вопрос в начале поста даёт больше охвата чем утверждение | Первая строка | Охват, лайки |
| 2 | Видео процесса (угли → мясо) набирает больше, чем фото блюда | Формат | Просмотры, сохранения |
| 3 | Пост с конкретной ценой конвертирует лучше, чем без цены | Цена в тексте | Переходы/звонки |
| 4 | Пятничные посты в 12:00 vs 17:00 | Время публикации | Охват |
| 5 | Упоминание настоек повышает интерес к основному меню | Кросс-продукт | Комментарии |
